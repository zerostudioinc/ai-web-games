# Web Games
This repo contains AI assisted 2D web based games. They are 2D browser-based games implemented using Vite, TypeScript, and Phaser 3.

## Balloon Catapult
This is a simple 2D web based game that can have 1 to 4 players. The objective of the game is for the player to protect their catapult from oncoming wave of walking bombs, the players will fire water balloon from their catapult to stop the oncoming bombs. The player can control an aim reticle and press shoot to fire their water ballon to. The player can connect a bluetooth controller to control the reticle using the directional pad and press any button to fire the balloon. Touch control to fire is allowed when there is only 1 player.

See [balloon-catapult.md](games/balloon-catapult.md) for the game overview and requirements.
